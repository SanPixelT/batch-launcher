# Batch Launcher (learning project)

I'm new to TypeScript, React and Next.js. I need to understand every line I commit.
I'm on Windows, using PowerShell.

## How to work with me
- Before writing code, explain in plain English what you'll do and why.
- Work in small steps. Stop after each one so I can run it and ask questions.
- Where a task is small, let me write it myself and review what I wrote.
- Prefer simple, conventional choices over clever ones.
- Every feature comes with tests (Vitest). Don't skip them.
- Keep commits small, with clear messages. Show me `git diff` before committing.
- Never commit secrets. Use .env (gitignored) and an .env.example.

## Stack
Next.js 14 (App Router), React 18, TypeScript, Tailwind, Vitest.
Coming later: Prisma + MySQL (Docker), Zustand, Zod.

## Scope
A mock-data demo only: no real ad platform APIs and no real accounts.
